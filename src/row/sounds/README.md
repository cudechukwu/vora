# Recordings

Drop audio files here and the game uses them instead of its synthesised sounds.
No code changes are needed; the file name is the sound. Formats: .m4a (iPhone Voice Memos), .mp3, .wav, .ogg.

Loops (30–90 s, start and end at a similar level so they loop cleanly):
- `day.m4a`: daytime campus ambience (birds, distant voices, wind). Replaces the synthesised birds.
- `night.m4a`: night ambience (crickets, quiet). Replaces the crickets.
- `traffic.m4a`: High Street from the sidewalk: the hum of passing cars.
- `crowd.m4a`: a busy room, e.g. Usdan at lunch.
- `room.m4a`: quiet indoor room tone.

One-shots (trim the silence at the start):
- `horn.m4a`: a car horn
- `car_door.m4a`: a car door shutting
- `house_door.m4a`: a wooden front door opening and closing
- `glass_door.m4a`: a glass push door (Usdan)
- `thud.m4a`: something heavy hitting a car body
- `jump.m4a`, `land.m4a`: optional

Voices (as many as you like; one is picked at random):
- `yell_1.m4a`, `yell_2.m4a`, …: "hey!!", "watch where you're going!", "are you serious?!", "get out of the road!"
- `hey_1.m4a`, `hey_2.m4a`, …: friendly greetings for roommates ("yo, you're back!")
